# Colheita Feliz 2 — v1.5.0

## Loja reorganizada
- Cada categoria da loja passa a ocupar uma seção visual própria.
- Barra de navegação fixa com atalhos para as categorias; clique para rolar diretamente até a seção.
- Cartões com espaçamento, grade responsiva e hierarquia visual mais clara.
- Em telas estreitas, os atalhos se distribuem em duas colunas e os produtos em duas colunas.

## Compatibilidade
- Nenhuma alteração no modelo de dados ou no formato do salvamento.
- Preços, custos, inventários, disponibilidade e funções de compra permanecem iguais aos da v1.4.0.
- API local e armazenamento Go mantidos; versão da aplicação atualizada para 1.5.0.
